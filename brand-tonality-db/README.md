# 品牌调性数据库

这是展示型独立站接单的地基，不是插件清单的再版。

接单时先判断客户品牌「像什么、不像什么」，再决定动效、字体、图墙和询盘怎么做。插件和灵感站是证据，标签才是可复用的判断语言。

适用客户：民宿与山居、独立咖啡馆、花艺工作室、摄影档期、婚礼场地、中医理疗馆等需要把气质展示给客人看的品牌。不做跨境电商壳，也不做简陋小程序壳。

## 怎么用

1. 听客户口述、看他们现有照片和文案，用 [01-dimensions.md](01-dimensions.md) 四个（加两个）维度各打一枪：偏高级、偏廉价、还是还没成形。
2. 从 [02-tag-system.md](02-tag-system.md) 里勾 3 到 6 个标签，写进提案。每个标签都有「客人能感觉到什么」和正反案例，避免只报插件名。
3. 标签里的插件与站点是取材来源，不是必须全上。宁可少做一个动效，也不要用标签堆出一套互抢戏的页面。

## 取材（截至 2026-11-06）

- 品牌调性插件库：42 项（动效/滚动/转场，高级感 UI，字体与排版，图片与摄影展示，预约/咨询/表单，建站脚手架与 CMS，前端特效）
- 有格调展示站灵感库：15 站（松赞、东山大观、煮屿 BREW ISLAND、影途山居、PALA、瓦厂酒店、白日梦旅行、几束花 Florette、Lyze Coffee、爱玛宫婚礼公园、Moss Design Studio、裕和堂、求索咖啡、随园花事、TANG VISION）

插件库和灵感库会继续更新。这里的标签不随每一条新收录改名；新工具或新站点如果只是已有标签的新证据，加到对应案例即可。只有出现新的可感知气质时，才新增标签。

## 维护约定

- 不在本目录存放账号、密码、token 或客户未公开的商业机密。
- 案例只写公开仓库和公开官网。站点气质依据灵感库已核验的表述，不编造流量或奖项。
- 许可风险（GSAP 自有许可、AGPL 预约系统、字体商用授权、Fancyapps 需商业授权等）以插件库原文为准，本库不替其背书。
