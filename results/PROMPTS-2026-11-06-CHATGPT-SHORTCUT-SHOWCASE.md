# ChatGPT-Shortcut 精选提示词（展示站向）

- 来源仓库：[rockbenben/ChatGPT-Shortcut](https://github.com/rockbenben/ChatGPT-Shortcut)（MIT）
- 数据文件：`src/data/prompt_zh-Hans.json`（2026-11-06 拉取）
- 用途：服务「有格调展示型独立站」——民宿、咖啡馆、花艺、摄影、婚礼场地、中医理疗
- 说明：只摘 22 条相关条目；**未整库复制**。正文以仓库中文 description 为主，并附可替换占位符的精简用法；完整英文 prompt 可回源查看。
- 在线浏览：[aishort.top](https://www.aishort.top/)
- 整理时间：2026-11-06（America/Los_Angeles）

## 怎么用

1. 把括号里的占位符换成客户行业与具体卖点（例如「莫干山山林民宿」「周末花艺体验课」）。
2. 先用调研/结构类提示词定栏目与故事，再用文案/SEO 类产出页面文案。
3. 事实、价格、资质类内容必须人工核验；提示词产出不当作医疗/法律建议。

## 1. 写作标题生成器

- **用途**：生成展示站首页/栏目的吸引人标题
- **场景备注**：民宿、咖啡馆、花艺等落地页主标题与栏目名
- **分类**：SEO标题
- **仓库 ID / 热度**：#8 / weight≈9262
- **标签**：write
- **来源链接**：[https://www.aishort.top/prompts/8](https://www.aishort.top/prompts/8)
- **上游出处**：https://github.com/f/awesome-chatgpt-prompts#act-as-a-title-generator-for-written-pieces

**提示词（精简/中文描述，可直接改占位符使用）：**

