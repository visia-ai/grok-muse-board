# 三角洲行动 · 电脑调优安全清单（远程服务 SOP v1）

用途：闲鱼远程调优服务（78 元档）的标准作业清单。原则只有一条：**只动系统层和驱动层，全部可逆，调前留底、调后留图**。

---

## 〇、红线（任何情况都不做）

- ⛔ 不超频（CPU/显卡/内存 XMP 以外的一律不碰；XMP/EXPO 只提示、不代开，出问题算不清）
- ⛔ 不刷 BIOS/显卡固件，不改电压
- ⛔ 不碰游戏文件、不改游戏配置目录之外的注册表游戏项、不装任何"防封/过检测/优化注入"类软件
- ⛔ 不在游戏运行时挂任何脚本、宏、连点器（腾讯 ACE 反作弊，封号风险全在卖家身上）
- ⛔ 不删系统服务、不关杀毒、不关防火墙、不动客户的账号/文档/隐私文件
- ⛔ 不装来路不明的"游戏优化器""驱动包"（只用官网：NVIDIA App / AMD Adrenalin / 品牌官网）
- ⛔ 远程全程客户在场，结束立即断开并提醒客户改远程软件临时密码/关无人值守

## 一、调前必做（10 分钟，跳过这步不出问题也要吵架）

- ☐ 问诊表收齐：CPU / 显卡 / 内存容量频率 / 显示器型号（面板上限 Hz）/ 连接线（DP 还是 HDMI）/ 系统版本 / 装机盘剩余空间 / 三角洲装在哪个盘
  - 收集路径（子睿 2026-11-06 定）：用子睿本机上的豆包 2.1 Lite（本地跑）整理客户聊天记录或截图，对齐清单必填项：CPU、显卡、内存容量与频率、显示器型号与面板上限 Hz、连接线（DP / HDMI）、系统版本、装机盘剩余空间、三角洲装在哪个盘。缺项再向客户追问
  - G哥只根据整理好的问诊结果出判断，不接触客户电脑
  - 不要把客户的远程账号/密码或带隐私的桌面截图发到任何云端；信息留在子睿本机
  - 豆包不代操客户电脑、不改设置
- ☐ 建系统还原点：Windows 给系统文件、驱动和设置留一张快照，调优出问题可以退回去；不删客户的文档和照片。任何驱动或设置改动之前就建好，客户在场，觉得不会出问题也不能跳过
  - 创建（Windows 10/11）：搜索「创建还原点」→ 打开「创建还原点」→ 系统保护窗口点「创建」→ 名字填「调优前-日期」→ 等完成。系统保护若是关的，先给系统盘（一般是 C:）打开：启用系统保护，磁盘使用量留几 GB
  - 出问题时恢复：搜索「恢复」→「恢复」→「下一步」→ 选这个命名的还原点 → 确认。电脑会重启。交付时把这条路径告诉客户
- ☐ 原始设置截图留底：当前刷新率、显卡面板主要页、游戏内画质页、任务管理器帧率（进游戏基准场景截一张"调前帧数"）
- ☐ 跟客户对一遍边界：本次只调设置、不承诺具体帧数数字、所有改动可还原

## 二、显示（最容易出效果的一段，很多人卡在这里）

- ☐ 刷新率拉满：Windows 设置 → 显示 → 高级显示 → 选面板上限（如 300Hz）；再进显卡面板确认同一数值，两边不一致以低的为准排查
- ☐ 线材核查：高刷必须 DP 或 HDMI 2.0 以上线；还是老 HDMI 1.4 线的，只提示客户换线，本项标记"待换线"不硬调
- ☐ 显示模式：独显直连（笔记本有混合输出的，确认游戏走独显；改输出模式需要重启进 BIOS 的，只提示不代改）
- ☐ G-Sync / FreeSync：面板和显示器两端都打开（显示器 OSD 里也要开）
- ☐ 缩放执行：由 GPU 执行缩放（显卡面板内设置），纵横比选"全屏"

## 三、显卡设置

### N 卡（NVIDIA 控制面板 / NVIDIA App）

- ☐ 驱动更新到官网最新（NVIDIA App 内更新；出问题概率极低，但仍放在还原点之后做）
- ☐ 管理 3D 设置（可只给三角洲程序单独建配置文件，不动全局）：
  - 电源管理模式 → 最高性能优先
  - 低延迟模式 → 超高（若游戏内开了 NVIDIA Reflex，以游戏内为准，此项改回"关"避免冲突，二选一，只留一处生效）
  - 纹理过滤-质量 → 高性能
  - 垂直同步 → 关（游戏内同步也关，用帧率上限控撕裂）
  - 首选刷新率 → 最高可用
  - 各向异性过滤 → 由应用程序控制（游戏内开）
- ☐ 数字振动/色彩类只按客户喜好调，标注"非性能项"

### A 卡（AMD Adrenalin）

- ☐ 驱动更新到官网最新（Adrenalin 内更新）
- ☐ 游戏配置文件（只给三角洲建档）：
  - Radeon Anti-Lag → 开
  - 等待垂直刷新 → 始终关闭
  - 纹理过滤质量 → 性能
  - 表面格式优化 → 开
  - Radeon Chill → 关（它会压帧，和冲帧目标冲突）
  - FreeSync → 开（显示器支持时）
- ☐ Fluid Motion Frames / FSR 的开关只在游戏内方案里统一给，不两边乱开

## 四、Windows 系统

- ☐ 电源计划 → 卓越性能（没有就新建：powercfg -duplicatescheme e9a42b02-d5df-448d-aa00-03f14749eb61）；笔记本插电使用才生效，提前说清
- ☐ 游戏模式 → 开
- ☐ 硬件加速 GPU 计划 → 开（设置 → 显示 → 图形 → 默认图形设置；需重启，放在最后统一重启）
- ☐ Xbox Game Bar 后台录制/游戏捕获 → 关（吃帧且占资源）
- ☐ 鼠标：取消"提高指针精度"（即鼠标加速，FPS 必关）；游戏内原始输入优先
- ☐ 开机自启：只关客户能叫出名字的软件（微信/QQ/网盘之类逐项经客户确认），系统项、驱动项、杀毒一律不动
- ☐ 游戏盘空间：不足 10% 时只提示清理，不代删文件

## 五、游戏内（三角洲，按显卡档位给模板）

通用项（所有档位）：

- ☐ 显示模式 → 全屏；分辨率 = 显示器原生；帧率上限 = 刷新率或不限（按客户温度/噪音偏好二选一，提前问）
- ☐ 垂直同步关；N 卡 Reflex → 开+加速（A 卡用游戏内低延迟选项）
- ☐ 超分：DLSS/FSR 先给"质量"档，帧数不够再降"平衡"；不直接上性能档糊画面
- ☐ 渲染比例 100%，不拿降渲染冒充优化

分档思路（示例口径，实际按客户机型填）：

- 入门（GTX 1660 / RX 6600 及以下）：中低画质保帧，阴影低、特效低、视距中
- 主流（RTX 3060–4070 / RX 6700–7800）：中高画质，纹理高、阴影中、特效中
- 高端（RTX 4070 Ti 以上）：高画质 + 高帧，纹理极高，其余按帧数目标微调

## 六、外设与网络（只建议，不代购、不代改账号设置）

- ☐ 鼠标回报率确认到 1000Hz（品牌驱动里看）；无线鼠提醒接收器放桌面近距离
- ☐ 网络：能插网线就不用 Wi-Fi；延迟高建议加速器（只报名字，不卖卡、不贴返利链接到客户机器上）
- ☐ 后台占带宽的下载/网盘同步，提醒客户开游戏前暂停

## 七、调后验证与交付（决定好评的一步）

- ☐ 同场景复测：和调前同一基准场景（训练场/同一地图路线）截"调后帧数"图
- ☐ 调前/调后对比图发客户确认
- ☐ 发《改动清单》：逐项写明"改了什么、原值是多少、在哪改回去"（照本清单二至五节勾选导出即可）
- ☐ 告诉客户还原点位置和一键还原路径，售后期口径：X 天内设置相关问题免费复调一次（自己上架时定天数）
- ☐ 断开远程，提醒客户关闭远程软件的无人值守/改临时密码
