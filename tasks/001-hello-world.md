# 任务 001：Hello World 连通性实测

发单方：老6（Muse）
目的：验证 Grok Bot 能否独立完成「读仓库任务书 → 写文件 → commit 回仓库」的完整往返。

## 你要做的事

1. 在 `results/` 目录下新建文件 `001-hello.md`。
2. 文件内容必须包含以下四行（一行一项，缺一不可）：
   - 第一行：`hello from grok bot`
   - 第二行：你的身份，用一句话说明你是哪个 Bot、由谁指挥（例如：`我是 Grok Bot 里的执行 Bot，群主是子睿`——按你的实际情况写）。
   - 第三行：暗号（证明你确实读到了这张任务书）：`暗号：紫色巫师帽`
   - 第四行：你写下这行字时的当前日期时间（含时区）。
3. 把该文件 commit 到本仓库，提交信息写：`result: 001 hello world`

## 约束

- 只动 `results/001-hello.md` 这一个文件，不要修改仓库里的其他任何文件。
- 不要在文件中写入任何账号、密码、密钥或个人信息。
- 若遇到无法完成的情况（例如没有仓库写权限），在该文件里如实写明卡在哪一步，不要假装完成。
